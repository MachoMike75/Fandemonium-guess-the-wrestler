# Fandemonium — Guess the Wrestler

Mobile-friendly, host-controlled Guess Who style wrestling game.

## Controls
- **NEW GAME** resets the mystery and all tiles.
- **SET MYSTERY** lets the host manually choose the mystery wrestler.
- **SHOW ANSWER** reveals the selected wrestler.
- **STAND ALL UP** restores every knocked-down tile.
- Tap any wrestler tile to knock it down. Tap the mystery wrestler to trigger the huge green **WINNER!** screen.

## GitHub Pages
The repository includes a GitHub Actions Pages deployment workflow. In GitHub, open **Settings → Pages**, choose **GitHub Actions** as the source, save, and push/refresh `main`. The workflow will deploy the site.
